# প্রশ্নপত্র তৈরি (React)

Word-এর মতো সহজ প্রশ্নপত্র এডিটর। A4 পেপারের ওপর সরাসরি লিখুন, বোতাম চেপে প্রশ্ন, উপ-প্রশ্ন (ক. খ. গ.), টেবিল, ভগ্নাংশ ও √ যোগ করুন, শেষে PDF করুন। কোনো কোড বা নিয়ম শেখার দরকার নেই।

## চালানোর নিয়ম

```bash
npm install
npm run dev      # ডেভেলপমেন্ট সার্ভার
npm run build    # প্রোডাকশন বিল্ড (dist/ ফোল্ডারে)
npm run preview  # বিল্ড করা ভার্সন দেখুন
```

Node.js 18 বা তার উপরের ভার্সন লাগবে। শুধু `react` ও `react-dom` ব্যবহার হয়েছে, আর কোনো এডিটর লাইব্রেরি নেই।

## শিক্ষকদের জন্য ব্যবহারবিধি

1. পেপারের ওপরের ঘরগুলোতে ক্লিক করে লিখুন: স্কুলের নাম, সেকশন, পরীক্ষার নাম, বিষয়, শ্রেণি, সময়, পূর্ণমান।
2. **＋ প্রশ্ন** চাপুন। প্রশ্ন লিখুন, ডানদিকের ছোট ঘরে নম্বর দিন (`১০` বা `১×১০ = ১০`)। প্রশ্ন নম্বর (১। ২। ৩।) নিজে থেকে বসে।
3. **ক. খ. গ.** মেনু থেকে উপ-প্রশ্ন বা MCQ অপশন (২ কলামে) বসান।
4. **▦ টেবিল**, **ভগ্নাংশ / √**, **চিহ্ন**, **……… শূন্যস্থান** দরকার মতো যোগ করুন। ভগ্নাংশের ওপর ডাবল ক্লিক করলে বদলানো যায়।
5. প্রশ্নের ভেতরে ক্লিক করলে **↑ উপরে / ↓ নিচে / ⧉ কপি / ✕ মুছুন** বোতাম আসে। ভুল হলে **↶ ফিরুন**।
6. **🖨️ PDF / প্রিন্ট** চেপে প্রিন্টারের জায়গায় **Save as PDF** বাছুন। কাগজ A4, মার্জিন ১০ মিমি (narrow) আগে থেকেই ঠিক করা।

লেখা ব্রাউজারে নিজে থেকে সেভ হয়। উপরের **📄 উদাহরণ** চাপলে একটি পূর্ণ নমুনা পেপার দেখা যায়।

## ফাইল কাঠামো

```
src/
  App.jsx        টুলবার, ডায়ালগ (টেবিল, ভগ্নাংশ, PDF নির্দেশনা)
  editor.js      এডিটরের মূল কোড: সিলেকশন, আনডু/রিডু, প্রশ্ন ব্লক, টেবিল, ভগ্নাংশ
  templates.js   খালি পেপার ও উদাহরণ পেপারের HTML
  ui.jsx         বোতাম, মেনু, মডাল
  App.css        A4 পেপার, প্রিন্ট সেটিং, প্রশ্ন নম্বর (CSS counter)
```

## জানা সীমাবদ্ধতা

- পেজ ব্রেক প্রিন্টের সময় ব্রাউজার ঠিক করে। কোনো প্রশ্ন দুই পাতায় ভাঙে না, তাই স্ক্রিনের ধূসর রেখার সাথে সামান্য ফারাক হতে পারে।
- মোবাইলে পুরো A4 পেজ ছোট করে দেখানো হয়। লেখার সময় পিঞ্চ করে জুম করে নিন।
- বাংলা ফন্ট Google Fonts থেকে লোড হয়, তাই প্রথমবার ইন্টারনেট লাগে।
