# প্রশ্নপত্র তৈরি

**শিক্ষকদের জন্য বিনামূল্যের, সহজ প্রশ্নপত্র তৈরির অ্যাপ।** মোবাইল ও কম্পিউটার, যেকোনো ডিভাইস থেকে চলে। কোনো বাড়তি জ্ঞান লাগে না।

Word-এর মতো সহজ এডিটর। A4 পেপারের ওপর সরাসরি লিখুন, বোতাম চেপে প্রশ্ন, উপ-প্রশ্ন (ক. খ. গ.), টেবিল, ভগ্নাংশ ও √ যোগ করুন, শেষে PDF করুন।

---

## এই অ্যাপের গল্প

বাংলাদেশের অনেক শিক্ষককে প্রতিটি পরীক্ষার আগে প্রশ্নপত্র বানাতে ঘণ্টার পর ঘণ্টা কাটাতে হয়। কখনো Word-এর জটিল টুলে, কখনো হাতে লিখে, কখনো ফটোকপির দোকানে ছুটে। বাংলা লেখা, ক খ গ-এর ভাগ, নম্বর বসানো, টেবিল ও গণিতের চিহ্ন সামলানো সবার জন্য সহজ নয়। আর অনেকের হাতে কম্পিউটারই নেই, আছে শুধু একটি মোবাইল।

এই কথাগুলো ভেবেই শিক্ষকদের সহায়তা করার জন্য ডেভেলপার **মোহাম্মদ আশিকুর রহমান** তৈরি করেছেন "প্রশ্নপত্র তৈরি"।

- **সম্পূর্ণ বিনামূল্যে।** কোনো টাকা, সাবস্ক্রিপশন বা রেজিস্ট্রেশন লাগে না।
- **যে কেউ, যেকোনো ডিভাইস থেকে।** মোবাইল হোক বা পিসি, ব্রাউজার থাকলেই হলো।
- **বাড়তি জ্ঞানের দরকার নেই।** যিনি সাধারণ মোবাইল চালাতে পারেন, তিনিই অনায়াসে এই অ্যাপ চালাতে পারবেন।
- **প্রশ্ন ও নম্বর নিজে থেকে গোছানো।** প্রশ্ন নম্বর বসে, নম্বরের যোগফল মেলে, ভুল হলে সতর্ক করে।
- **ফোনে বানানো PDF আর পিসিতে বানানো PDF একই রকম।** মার্জিন ও মাপ সব ডিভাইসে ঠিক থাকে।

লক্ষ্য একটাই: শিক্ষকের সময় বাঁচানো, আর প্রশ্নপত্র হোক পরিপাটি ও নির্ভুল।

---

## কী কী করা যায়

- স্কুলের নাম, পরীক্ষার নাম, বিষয়, শ্রেণি, সময় ও পূর্ণমান পেপারেই লেখা
- প্রশ্ন, উপ-প্রশ্ন (ক. খ. গ.) ও MCQ অপশন (২ কলামে)
- টেবিল, ভগ্নাংশ, ঘাত, √ ও বিভিন্ন চিহ্ন, শূন্যস্থান
- টেক্সট বক্স ও ছবি বসানো
- মোট প্রশ্ন ও নম্বরের যোগফল সবসময় ওপরে দেখা, পূর্ণমানের সঙ্গে না মিললে সতর্কতা
- আনডু / রিডু, লেখা ব্রাউজারে নিজে থেকে সেভ
- বাংলা ও ইংরেজি দুই ভাষায় লেবেল, ফন্ট ও লেখার মাপ বদলানো
- পোর্ট্রেট / ল্যান্ডস্কেপ, নিজের মতো মার্জিন

### PDF ও প্রিন্ট

- **১ কপি, ২ কপি বা ৪ কপি** একই A4 পাতায়।
- ২ কপি হলে বেছে নেওয়া যায়: **পাশাপাশি** (ল্যান্ডস্কেপ পাতা) অথবা **উপর-নিচে** (পোর্ট্রেট পাতা)।
- প্রতি কপি **আনুমানিক কত শতাংশ আকারে** বসবে, তা ডায়ালগেই দেখা যায়। লেখা বেশি হলে কপি অনেক ছোট হয়ে যাবে এই সতর্কতাও আসে। লেখা বাড়লে বা কমলে হিসাব নিজে থেকেই নতুন হয়।
- PDF বানানোর পর **প্রিভিউ দেখে** তারপর ডাউনলোড করা যায়।
- ফাইলের নাম আসে পেপারের বিষয় ও শ্রেণি থেকে, যেমন `বাংলা-৬ষ্ঠ.pdf`।
- PDF অ্যাপের ভেতরেই নির্দিষ্ট A4 মাপে আঁকা হয়, তাই ফোন বা কম্পিউটার বা ব্রাউজারের নিজস্ব মার্জিন ও জুমের ওপর নির্ভর করে না।

### মোবাইলে সুবিধা

- পুরো A4 পেপার ছোট করে দেখানো হয়, দুই আঙুলে জুম করে লেখা যায়।
- প্রশ্ন বা টেবিল সিলেক্ট করলে নিচে যে বাটনের বার আসে, কিবোর্ড খুললে সেটি কিবোর্ডের ওপরে উঠে আসে, কিবোর্ড সরলে আগের জায়গায় নেমে যায়।
- টুলবার একটি ড্রয়ারে থাকে, দরকার হলে খোলা যায়।

## শিক্ষকদের জন্য ব্যবহারবিধি

1. পেপারের ওপরের ঘরগুলোতে ক্লিক বা ট্যাপ করে লিখুন: স্কুলের নাম, পরীক্ষার নাম, বিষয়, শ্রেণি, সময়, পূর্ণমান।
2. **＋ প্রশ্ন** চাপুন। প্রশ্ন লিখুন, ডানদিকের ছোট ঘরে নম্বর দিন (`১০` বা `১×১০ = ১০`)। প্রশ্ন নম্বর (১। ২। ৩।) নিজে থেকে বসে।
3. **ক. খ. গ.** মেনু থেকে উপ-প্রশ্ন বা MCQ অপশন বসান।
4. **টেবিল**, **ভগ্নাংশ / √**, **চিহ্ন**, **শূন্যস্থান** দরকার মতো যোগ করুন। ভগ্নাংশের ওপর ডাবল ক্লিক করলে বদলানো যায়।
5. প্রশ্নের ভেতরে ক্লিক করলে **↑ উপরে / ↓ নিচে / ⧉ কপি / ✕ মুছুন** বাটন আসে। ভুল হলে **ফিরুন**।
6. ওপরের **PDF / প্রিন্ট** চাপুন। ১, ২ বা ৪ কপি বাছুন, **PDF / প্রিন্ট করুন** চাপুন, প্রিভিউ দেখে ডাউনলোড করুন। প্রিন্ট করতে ডাউনলোড করা ফাইলটি খুলে প্রিন্ট দিন।

লেখা ব্রাউজারে নিজে থেকে সেভ হয়। **উদাহরণ** চাপলে একটি পূর্ণ নমুনা পেপার দেখা যায়।

## ডেভেলপারদের জন্য: চালানোর নিয়ম

```bash
npm install
npm run dev      # ডেভেলপমেন্ট সার্ভার
npm run build    # প্রোডাকশন বিল্ড (dist/ ফোল্ডারে)
npm run preview  # বিল্ড করা ভার্সন দেখুন
```

Node.js 18 বা তার উপরের ভার্সন লাগবে।

### ব্যবহৃত প্রযুক্তি

| কাজ | প্রযুক্তি |
|---|---|
| ইন্টারফেস | React (`react`, `react-dom`) |
| এডিটর | নিজস্ব কোড (`editor.js`), কোনো বাইরের এডিটর লাইব্রেরি নেই |
| PDF তৈরি | `html2canvas` ও `jspdf` (`pdfExport.js`) |
| স্টাইল | সাধারণ CSS (`App.css`), কোনো CSS ফ্রেমওয়ার্ক নয় |

PDF-এর লাইব্রেরি আলাদা করে বসাতে হলে:

```bash
npm install html2canvas jspdf
```

### ফন্ট

বাংলা লেখার জন্য **Nikosh** ও **SutonnyOMJ** ফন্ট ব্যবহার হয়। ফাইলগুলো `public/fonts/` ফোল্ডারে রাখতে হবে (`Nikosh.ttf`, `SutonnyOMJ Regular.ttf`)। ডিভাইসে ফন্ট বসানো থাকলে সেটিই আগে ব্যবহার হয়।

### ফাইল কাঠামো

```
src/
  App.jsx          টুলবার, ডায়ালগ (টেবিল, ভগ্নাংশ, PDF সেটিংস ও প্রিভিউ)
  editor.js        এডিটরের মূল কোড: সিলেকশন, আনডু/রিডু, প্রশ্ন ব্লক, টেবিল, ভগ্নাংশ, পেজ ভাগ
  pdfExport.js     নির্দিষ্ট A4 মাপে PDF তৈরি, ১/২/৪ কপির বিন্যাস, কপির মাপের হিসাব
  templates.js     খালি পেপার ও উদাহরণ পেপারের HTML
  ui.jsx           বাটন, মেনু, মডাল
  icons.jsx        টুলবারের আইকন
  App.css          অ্যাপের ডিজাইন, A4 পেপার, প্রশ্ন নম্বর (CSS counter)
public/
  fonts/           Nikosh ও SutonnyOMJ ফন্ট
```

### PDF কীভাবে একই থাকে

`window.print()` ব্যবহার করলে প্রতিটি ডিভাইস ও ব্রাউজার নিজের মতো মার্জিন, কাগজের মাপ ও জুম ঠিক করে, ফলে ফোন ও পিসিতে ভিন্ন PDF আসে। তাই `pdfExport.js` পেপারের একটি কপি নির্দিষ্ট মাপে (১ মিমি = সবসময় একই সংখ্যক পিক্সেল) আঁকে, স্ক্রিনের জুম বাদ দেয়, তারপর `jspdf` দিয়ে A4 পাতায় বসায়। ২ ও ৪ কপির সময় কপিগুলো পাতার ঘরে মাপ করে বসে এবং কপির মাঝখানে কাটার জন্য ড্যাশ দাগ থাকে।

### ডিজাইন

রঙের ভিত্তি বোতল-সবুজ, সোনালি ও পতাকার লাল। স্ক্রিনের ডিজাইন `App.css`-এর `@media screen` অংশে, তাই পেপার ও PDF-এর ওপর এর কোনো প্রভাব নেই। রং বদলাতে চাইলে ওই অংশের `--g-700`, `--gold`, `--flag-red` ভেরিয়েবল বদলান।

## জানা সীমাবদ্ধতা

- PDF ছবি হিসেবে আঁকা হয়, তাই PDF-এর লেখা সিলেক্ট বা কপি করা যায় না। প্রিন্টে লেখা পরিষ্কার আসে।
- ২ বা ৪ কপিতে লেখা বেশি থাকলে প্রতি কপি ছোট হয়ে যায়। ডায়ালগে আনুমানিক শতাংশ দেখে সিদ্ধান্ত নিন।
- মোবাইলে পুরো A4 পেজ ছোট করে দেখানো হয়। লেখার সময় দুই আঙুলে জুম করে নিন।
- ফন্ট ফাইল না থাকলে বাংলা লেখা অন্য ফন্টে দেখা যেতে পারে।
